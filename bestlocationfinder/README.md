# ExplorePlace Frontend

This directory contains the React frontend for **ExplorePlace**, a full-stack travel discovery platform for Indian cities.

For the complete product overview, architecture, setup guide, API documentation, and engineering decisions, see the [main project README](../README.md).

## Frontend commands

```bash
npm install
npm start
npm test
npm run build
```

The development server runs at `http://localhost:3000`. By default, it expects the backend at `http://localhost:5000`. Set `REACT_APP_API_URL` in a local `.env` file to use another API URL.
